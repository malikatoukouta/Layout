# Galerie de projets CSS grid

Projet réalisé pour pratiquer :

- HTML sémantique
- CSS Grid
- Flexbox
- Responsive design (mobile-first)
- Variables CSS
- Animations CSS
- Transitions
- Dark mode avec prefers-color-scheme
- Accessibilité

## Aperçu

Cette galerie utilise :

```css
grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
```

pour créer des colonnes responsives automatiques.

## Technologies utilisées

- HTML5
- CSS3
- Git
- GitHub Pages
